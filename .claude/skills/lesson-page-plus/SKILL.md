# 수업 화면·학습지 개선판 만들기 (공개용)

중학교 음악 수업용 정적 웹페이지(바닐라 JS, GitHub Pages)를 "그럴싸한 수업 화면"으로 만드는 기준.
판소리 개선판(`pansori-plus`)에서 정리했다. 이 저장소의 CLAUDE.md 규칙이 먼저다.
**공개 저장소**이므로 비밀 키·시트 주소·학생 정보·개인 연락처는 어떤 파일에도 넣지 않는다.
작업자 PC에 보충용 전역 스킬(협업·검토 방식)이 있으면 그것도 함께 따른다.

## 1. 원본은 건드리지 않는다
- 개선은 **복사본 폴더**(`<이름>-plus/`)에서 한다. 원본 폴더는 한 글자도 고치지 않는다.
- 제출이 섞이지 않게 ws 이름·저장 이름을 새로 준다(예: `pansori-plus`, `pansori-plus-v1`).
- **문항 id·이름·정답은 원본과 똑같이** 둔다. 문항·흐름이 바뀌는 제안은 보류하고 선생님께 묻는다.
- 학습지 모음 첫 화면에 카드를 원본 카드 **위에** 단다.

## 2. 화면 원칙
- 따뜻한 어두운 무대(먹색 #14110e), **강조색은 하나**(주홍 #e8693f), 이모지 없음. 학습지는 장 끝의 밝은 종이 판(한지 #f4efe5).
- 왼쪽 목차(차시별 묶음, 장 아래 `학습지 n/m` 바로가기 `#장?sheet`) + 아래 고정 페이지 넘김.
- 장 끝에 본문 → 학습지 **디딤 안내** 한 줄("여기까지 봤으면 N문항…").
- **수업 모드**: 메뉴 숨김·전체 화면·큰 글씨, 학습지는 숨기고 `학습지 함께 보기` 토글(`body.class-sheet`)로 칠판에 띄움. 수업 모드를 끄면 토글도 초기화.
- 탭으로 나눈 내용은 탭을 **한 줄 유지 + 가로 스크롤**, 패널 끝에 `다음: ○○ →` 버튼, 마지막 패널은 `학습지로 →` 링크.
- 모바일(≤820px): 위쪽 고정 띠(56px)와 본문 위 여백을 같게, 목차가 열리면 목차 버튼을 숨겨 겹침을 막고, 버튼·칩은 높이 40px 이상. 안내 순서와 화면 순서를 `order`로 바꾸지 않는다.

## 3. 그림 — "글만 줄줄"을 막는 핵심
장마다 그림이 하나는 있어야 한다. 크기를 **규격화**한다.

| 쓰임 | 비율·크기 | 용량 | 비고 |
|---|---|---|---|
| 장면 그림(작품·이야기 카드) | 4:3, 1200×900 | 250KB 이하 | 탭·카드 위 |
| 무대·배치 그림 | 16:9, 1600×900 | 250KB 이하 | 장 첫머리 |
| 장 머리 배경 | 8:3, 1600×600 | 150KB 이하 | 어두운 바탕, 그림은 **오른쪽 1/3**에만, 왼쪽은 제목 자리 |

- 형식 webp(품질 80 근처, 넘치면 5씩 낮춤). 파일 이름 `madang-*`, `stage-*`, `head-<장id>` 처럼 쓰임이 보이게. png 원본은 저장소에 넣지 않는다.
- **한 사람이 그린 것처럼 같은 화풍**: 귀엽고 따뜻한 평면 일러스트, 고른 선·면 채색, 중학생에게 유치하지 않게. 3D·네온·사진풍 합성 금지.
- 그림 안에 글자(한글·한자·영문) 없음, 실존 인물 얼굴·로고 없음, 피·잔혹 없음.
- 그림 출처는 이미지 생성 도구(직접 만듦) 또는 퍼블릭 도메인·CC0·CC BY·CC BY-SA만. 교과서 그림·사진 금지.
- `img/CREDITS.md`에 파일마다 `파일 | 생성/출처 | 라이선스` 한 줄. 직접 만든 건 "생성".
- 장 머리처럼 은은한 배경은 **새로 그리지 말고 기존 장면 그림을 잘라 어둡게** 만든다(화풍이 저절로 맞음).
- 그림을 다른 사람·도구에 맡길 때는 위 표대로 파일 이름·픽셀 크기·장면 내용·화풍 규칙을 적어 주고, 수정 범위는 `img/` 새 파일로만 묶는다.

스크립트(`.claude/skills/lesson-page-plus/scripts/art.py`, Pillow 필요):
```bash
python art.py webp <img폴더> <저장소 밖 백업폴더>                  # png → webp, png는 밖으로 옮김
python art.py head <img폴더> madang-su.webp story 200 30 900 780  # 상자(x0 y0 x1 y1)를 잘라 head-story.webp
```
상자는 인물·소품이 있는 부분을 고르고, 장마다 다른 그림·부분을 써서 머리가 겹쳐 보이지 않게 한다.

### 그림을 페이지에 넣는 법
- 도우미 하나로 통일: `art(file, alt, cls, w, h)` → `<div class=cls><img class="art-img" src="img/file" alt width height loading="lazy" decoding="async">`. 너비·높이를 꼭 넣어 자리 밀림을 막고, 틀은 CSS `aspect-ratio`로 고정.
- alt는 장면을 한 문장으로(그림마다 다르게).
- 로드 실패 시 빈 틀이 남지 않게: `view.addEventListener('error', e => { if (e.target.classList?.contains('art-img')) e.target.parentNode.style.display='none' }, true)`.
- 장 머리: `class="ch-head art" style="--art:url(img/head-<id>.webp)"`, CSS는 왼쪽→오른쪽 어두운 그라데이션 위에 `var(--art) right center / cover`. 좁은 화면에선 덮개를 더 진하게.

## 4. 놓치기 쉬운 동작
- 지금 주소와 같은 링크(`#story?sheet`로 들어온 뒤 다시 `학습지로`)는 hashchange가 안 생긴다 → 본문·목차 클릭에서 `href === location.hash`면 직접 이동 함수 호출.
- 수업 모드에서 학습지가 숨겨진 채 학습지 링크를 누르면 먼저 학습지를 펼친 뒤 이동.
- 수업 모드 중 목차는 겹쳐 열리고, 장을 옮기면 닫힌다. 바깥(어두운 막)·Esc로도 닫힌다.
- 고친 뒤 `index.html`의 `?v=` 캐시 값을 올린다(Pages 캐시 최대 10분).

## 5. 확인 순서
1. `node --check app.js`.
2. 로컬 서버로 미리보기. 이름 덮개 창(`.cr-veil`)은 **JS로 숨기기만** 하고 절대 제출하지 않는다(가짜 이름도 제출 금지).
3. 1024px와 375px에서: 그림 로드(`naturalWidth`), 탭 한 줄, 위쪽 겹침, 가로 넘침(`scrollWidth`), 수업 모드·토글·목차, 콘솔 오류(새로고침 후 다시 확인).
   일부 미리보기 창은 smooth 스크롤이 움직이지 않는다 → 위치 확인은 `behavior:'instant'`로.
4. 다른 눈으로 읽기 전용 검토: 실제 버그만, 원본 문항 id·정답 일치도 확인. 지적은 직접 확인해 고칠 것만 고친다.
5. 커밋 전 비밀 검사(배포 키·시트 주소·이메일·전화번호가 diff에 없는지), png 미포함 확인 → 커밋·푸시.
6. 끝나면 CLAUDE.md 표의 해당 폴더 설명도 갱신.
